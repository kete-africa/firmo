# Technical decisions

One decision per file: `NNNN-short-title.md`. Each records what was decided, why, what it costs,
and what would reverse it. Entries are never deleted; a new entry supersedes an old one.

Product and company decisions live in the Kete doctrine (`kete-africa/kete`, `docs/DECISIONS.md`)
and, for Firmo's business rules, in `docs/product/`.
